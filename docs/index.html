FAQ

Does jev-stars need an API key? No. Search, rank, context, status, and export work offline with zero keys. Only curate needs TYPESAFE_API_KEY, once, and results cache by content hash.

How is this different from GitHub's stars page? GitHub gives you a paginated list. jev-stars gives your agent a bounded context object: health, license, Jev score, and evidence excerpt in ~2k tokens.

Why not vectors in v0.1? FTS5 answers 1,244 rows in 47ms. sqlite-vec lands in v0.2 only when FTS measurably falls short.

Limits

No vectors in v0.1 (sqlite-vec lands in v0.2). No TUI, no dashboard, no release tracker. No star/unstar. Read-only memory over your stars.
