FAQ

Does jev-stars need an API key? No. Search, rank, context, status, and export work offline with zero keys. Only curate needs TYPESAFE_API_KEY, once, and results cache by content hash.

How is this different from the GitHub stars page? GitHub gives a paginated list. jev-stars gives your agent a bounded context object: health, license, Jev score, and evidence excerpt in about 2k tokens.

No vectors in v0.1? FTS5 answers 1,244 rows in 47ms. BGE vectors landed in v0.2 with RRF hybrid, 330ms p50.

Limits? No TUI, no dashboard, no release tracker. No star or unstar. Read only memory over your stars.
